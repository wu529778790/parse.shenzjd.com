# 小程序接入抖音解析接口 —— 给 AI 的话术

> 直接把下面「话术正文」整段复制给小程序那边的 AI 即可。它已经包含了接口地址、参数、认证、返回结构、直播/视频/合集三种类型的处理逻辑，以及直播播放的完整方案。

---

## 话术正文

请帮我在小程序里接入抖音解析接口，实现「粘贴抖音分享链接 → 解析 → 播放/展示」的功能。接口和返回结构如下，请严格按此实现。

### 1. 接口信息

- **接口地址**：`GET https://parse.shenzjd.com/api/parse`（**统一解析入口**，所有平台共用，抖音直播/视频/合集都走这个）
- **请求参数**（query string）：
  - `url`：必填，抖音分享链接（支持短链 `v.douyin.com/xxx`、完整链接、直播链接、合集链接）
- **认证要求**：该接口需要微信认证。请求时需携带 `wxauth-token` Cookie（由 `wx-auth-sdk` 写入）。未认证时返回 `401`，提示「请先关注公众号并完成认证」。小程序端需先完成微信认证流程，拿到 token 后随请求带上。
- **说明**：`/api/parse` 是统一入口，会自动识别链接属于哪个平台（抖音/快手/B站等）并转发到对应解析器。抖音直播链接（`v.douyin.com` 短链）会被自动识别为抖音直播并返回直播流，**无需单独调 `/api/douyin`**。

### 2. 返回结构（统一契约）

```json
{
  "code": 200,
  "msg": "解析成功",
  "platform": "douyin",
  "data": {
    "type": "video | image | music | text | live",
    "title": "标题",
    "author": "作者名",
    "avatar": "作者头像",
    "cover": "封面图",
    "url": "主媒体直链",
    "duration": 0,
    "like": 0,
    "time": 0,
    "uid": "作者ID"
  }
}
```

- `code === 200` 表示解析成功；其他 code 为失败，`msg` 是失败原因，直接展示给用户即可。
- `platform` 是平台标识（抖音为 `douyin`），可用于区分来源。
- `data.type` 决定内容类型，**重点处理 `video` 和 `live` 两种**。

### 3. 视频类型（`type === "video"`）

普通视频/图文，直接播放 `data.url` 即可（直链 mp4）。

```json
{
  "code": 200,
  "data": {
    "type": "video",
    "title": "视频标题",
    "cover": "封面",
    "url": "https://.../video.mp4",
    "author": "作者",
    "avatar": "头像",
    "duration": 15000,
    "like": 1234
  }
}
```

### 4. 直播类型（`type === "live"`）—— 重点

直播返回额外字段：

```json
{
  "code": 200,
  "platform": "douyin",
  "data": {
    "type": "live",
    "title": "直播间标题",
    "author": "主播名",
    "avatar": "主播头像",
    "cover": "直播间封面",
    "url": "https://.../index.m3u8",          // HLS 直链（m3u8），优先用这个播放
    "liveStatus": 2,                            // 2=直播中，其他为未开播/已结束
    "liveViewerCount": "2.9万",               // 观看人数（字符串）
    "liveQualities": [                        // 多清晰度 FLV 流
      { "name": "蓝光", "url": "https://.../flv" },
      { "name": "超清", "url": "https://.../flv" }
    ],
    "roomId": "123456789",
    "shareUrl": "https://live.douyin.com/xxx"
  }
}
```

**直播播放逻辑：**

1. **判断是否直播中**：`data.liveStatus === 2` 表示正在直播，可以播放；否则提示「该直播间当前未开播或已结束」。
2. **播放地址**：优先用 `data.url`（HLS m3u8 流）。小程序端用 `<video>` 组件直接播放 m3u8 即可（微信小程序原生支持 HLS）。
3. **清晰度切换**（可选）：`data.liveQualities` 是多清晰度 FLV 流列表，如果小程序端需要清晰度切换，可让用户选择后播放对应 `url`。但注意 FLV 流在小程序 `<video>` 里不直接支持，需要转 HLS 或用 `live-player` 组件（`live-player` 支持 FLV/RTMP）。**最简单方案：直接用 `data.url`（m3u8）播放，无需处理清晰度。**
4. **直播流有时效性**：直播流地址带签名，有时效。如果播放失败，提示用户重新解析获取新链接。

### 5. 合集类型（`type === "video"` + `data.videos`）

合集链接返回时，`data.videos` 是视频列表数组，每项含 `title`、`url`、`cover`、`duration`，可展示为可点击的列表：

```json
{
  "code": 200,
  "data": {
    "type": "video",
    "title": "合集标题",
    "videos": [
      { "title": "第1集", "url": "https://.../1.mp4", "cover": "...", "duration": 10000 },
      { "title": "第2集", "url": "https://.../2.mp4", "cover": "...", "duration": 10000 }
    ],
    "totalEpisodes": 2
  }
}
```

### 6. 错误处理

- `code === 400`：参数错误（如链接不是抖音链接、是用户主页链接等），`msg` 已给出明确原因，直接展示。
- `code === 201`：解析失败（视频不存在/已删除/被风控/直播未开播等），`msg` 是原因，直接展示。
- `code === 401`：未认证，引导用户先完成微信认证。
- `code === 500`：服务器内部错误，提示稍后重试。

### 7. 实现建议

- 请求用 `wx.request`，`url` 参数用 `encodeURIComponent` 编码。
- 直播用 `<video>` 组件播放 `data.url`（m3u8），`autoplay` 开启。
- 视频用 `<video>` 组件播放 `data.url`。
- 解析前先展示 loading，拿到结果后按 `type` 分发到对应页面/组件。
- 直播流地址有时效，建议每次进入直播页都重新请求解析接口拿最新链接，不要缓存直播链接。

## 二、给小程序 AI 的补充说明（可选，不用复制）

如果小程序 AI 需要更精确的字段说明，可参考以下类型定义（与后端 `ParseData` 契约一致）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | string | `video` / `image` / `music` / `text` / `live` |
| `title` | string | 标题 |
| `desc` | string | 描述 |
| `author` | string | 作者名 |
| `avatar` | string | 作者头像 |
| `cover` | string | 封面图 |
| `url` | string | 主媒体直链（视频/直播 m3u8） |
| `duration` | number | 时长（毫秒） |
| `liveStatus` | number | 直播状态，`2`=直播中 |
| `liveViewerCount` | string | 观看人数 |
| `liveQualities` | array | 多清晰度 FLV 流 `[{name,url}]` |
| `roomId` | string | 直播间 ID |
| `shareUrl` | string | 直播间分享链接 |
| `videos` | array | 合集视频列表 `[{title,url,cover,duration}]` |
| `totalEpisodes` | number | 合集总集数 |
| `like` | number | 点赞数 |
| `time` | number | 发布时间 |
| `uid` | string | 作者 ID |
